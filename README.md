# GKza

ERP GKza — projeto gerado pela Skip.

## Stack

- React 19 + Vite + TypeScript + Tailwind CSS
- shadcn/ui
- PocketBase (Skip Cloud) com migrações e hooks em `pocketbase/`

## Rodando

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Projeto sincronizado via plataforma Skip.
